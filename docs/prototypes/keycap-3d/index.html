The one rule

Bake once. Blit many. Never light in the loop.

Everything realistic and expensive happens a single time — at theme/size change — and lands in the keyBgCache. The typing hot path only ever copies finished pixels.

Cheap Safe on the hot path

  • Blit a cached bitmap per key — one drawImage, zero allocation.
  • Swap rest ⇄ pressed tiles — both pre-baked, keyed by label|pressed.
  • Translate a pre-baked specular sprite for the moving-light highlight.
  • Offset two cached layers (face + wall) by tilt for real parallax.

Costly Bake-time only — never per frame

  • RadialGradient / BlurMaskFilter for the dish and soft AO — run once, cache the result.
  • Rebuilding GradientDrawable stacks on every draw instead of caching.
  • RenderEffect blur or elevation shadows on live views — forces a relayout storm.
  • Per-key overdraw from many translucent layers — flatten into the baked tile.
